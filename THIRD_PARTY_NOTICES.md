# Serviços e componentes de terceiros

PyMetaAudio integra ou pode integrar os seguintes projetos/serviços. Consulte sempre as licenças e termos atuais antes de redistribuir binários ou usar o software comercialmente.

- Python — PSF License.
- Mutagen — biblioteca de metadados.
- Pillow — processamento/validação de imagens.
- CustomTkinter — GUI.
- FFmpeg/ffprobe — conversão e validação; licença depende da build utilizada.
- yt-dlp — download/pós-processamento autorizado pelo usuário.
- Chromaprint/fpcalc — fingerprint acústico.
- AcoustID — serviço de lookup; serviço público gratuito voltado a uso não comercial e sujeito a rate limit.
- MusicBrainz — metadados; API pública sujeita a User-Agent/rate limit e condições próprias.
- Cover Art Archive — capas ligadas ao MusicBrainz.
- faster-whisper / CTranslate2 — transcrição local opcional.
- LRCLIB — serviço aberto de letras, sem API key, sujeito a User-Agent e rate limiting.
- Discogs API — segunda opinião opcional; dados/termos e atribuições próprios. O aplicativo deve exibir/fornecer atribuição quando dados Discogs forem apresentados ao usuário.

PyMetaAudio não inclui AudD no núcleo e não depende de API paga para sua função principal de identificação.
